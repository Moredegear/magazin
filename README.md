## Классы:
* Класс Продукты:
Родительский класс у классов Смартфонов и Газоно
общие аргументы имя описание цена и количество на складе
магический метод __add__ позволяет узнать общую стоимость всех товаров на складе двух разных товаров гланое что бы они были одинакого класса
метод new_product позволяет добавить новый продукт или в случае если такой на складе уже имееться обновить его колличесто и стоимость если она разница
* класс Category хранит информацию о категориях таваров
  (имя_категории,описание,список продуктов)
есть возможность добавить новый продукт в список или автоматически обновить количество этого тавара на складе
также есть счетчик общего количества категорий и продуктов
* Класс Order класс с информацией о заказе на какой-либо тавар 



## Инструкция по использованию функций:
* Функция get_class_from_json Реализует подгрузку данных по категориями и товарам из файла JSON.И создает список из класов
